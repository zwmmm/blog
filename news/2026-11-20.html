Veria Labs 披露 Ruby 核心与主流 Web 框架严重 RCE 漏洞 Ruby2ßhell：单字节堆溢出致未授权代码执行

AI编程

安全研究机构 Veria Labs 公布影响 Ruby 核心解释器及所有主流 Ruby Web 框架的高危漏洞 Ruby2ßhell（编号 CVE-2026-132825，GHSA-34m4-m9fh-gqp5）。该漏洞源于 Ruby 解释器在对特定 Unicode 大写字符（如德语大写双 S 字符 ß 与长 S 等）进行字符串大小写转换（upcase/downcase）时的单字节堆缓冲区溢出（Heap Overflow）。在 Ruby on Rails、Sinatra、Hanami 等流行框架的默认配置下，攻击者只需发送特制的未授权 HTTP 请求使服务端调用标准字符串大小写方法，即可触发堆内存越界写入并构造任意代码执行（RCE）链。该缺陷影响从 Ruby 2.4.0 至今长达数年的全系列版本，Ruby 官方与主要 Linux 发行版已紧急发布 3.3.14、3.4.13 与 4.0.10 补丁修复，建议所有生产环境服务尽快升级。
