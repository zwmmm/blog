Apple 推出 Pass Designer 与 Pass Builder：官方第一方 Wallet 凭证可视化设计套件

苹果在开发者平台正式推出 macOS 原生应用程序 Pass Designer 与配套的开源后端工具链 Pass Builder。开发者无需再手动编写繁琐的 pass.json 或凭空调试布局，即可通过 WYSIWYG 可视化编辑器设计登机牌、活动门票、会员卡等 Apple Wallet 凭证模板并实时预览原生渲染效果。配合 Swift 编写的 buildpass 命令行工具，可无缝打通后端自动化签名与分发流程。

官方资源：https://developer.apple.com/pass-designer/

Black Forest Labs 发布 FLUX 3 Image：支持细粒度画布区域控制与多参考图一致性生成

Black Forest Labs 正式发布新一代基座多模态生成模型 FLUX 3 Image。新模型不仅原生支持 2K 和 4K 超高清分辨率输出与更精准的文字排版渲染，还引入了细粒度画布区域编辑机制，允许开发者通过边界框定向修改画面局部而保持其余区域完全不变。同时模型支持单次生成中融合最多 10 张参考图进行风格与主体一致性保持，API 已全面上线，开源权重版本将在近期推出。

模型主页：https://bfl.ai/models/flux-3-image

OpenAI 推出 Sites in ChatGPT：自然语言零代码全栈轻应用生成与托管平台

OpenAI 在 ChatGPT 平台正式上线 Sites 功能，支持用户仅凭自然语言对话全自动构建、预览、迭代并一键部署交互式网页、内部业务工具与轻量游戏。生成的轻应用直接托管于平台云端并分配二级域名，内建轻量数据库、用户认证与表单处理支持，并允许团队成员多人协同编辑与绑定自定义域名，将智能体落地交付周期缩短至数分钟。

功能介绍：https://chatgpt.com/features/sites/

Louis-CFM 开源 coucou：基于 macOS 刘海屏与状态栏的 AI 编程智能体轻量监控伴侣

开源项目 coucou 为 macOS 开发者带来了一款常驻于屏幕刘海与状态栏的极简智能体交互伴侣。针对 Claude Code、Codex、Cursor、Gemini CLI 等终端与本地编程智能体，coucou 通过本地 Hook 机制实时捕获终端后台的工具调用与文件修改行为，将其转换为直观的图形化权限审批浮窗，并支持通过拖拽窗口与文件直接向智能体注入上下文。

项目仓库：https://github.com/Louis-CFM/coucou

AI编程 智能体 中推

yetone 开源 magpie：极简 macOS 菜单栏 AI 编程智能体多模型路由工具

Avante.nvim 作者 yetone 正式开源 macOS 菜单栏模型路由工具 magpie。项目旨在解决开发者在本地同时运行多个编程智能体时的模型配置割裂问题，通过菜单栏常驻面板统一管理与切换各个 Agent 的底层模型代理，支持一键将 Claude Code 切换路由至 Kimi、或将 Codex 路由至 DeepSeek 等高性价比国产大模型，降低多智能体协同开发的配置门槛。

项目仓库：https://github.com/yetone/magpie
