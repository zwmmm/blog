OpenAI 开源 Lean 4 数学定理证明形式化基准与预印本库

大模型 AI编程

OpenAI 宣布在数学前沿推理研究中取得实质突破，并同步在 GitHub 正式开源 math 仓库。该项目系统整理了基于 Lean 4 形式化交互式证明系统的数学预印本库与自动验证工具链，涵盖代数、数论与拓扑领域的严谨形式化代码，为大语言模型解决高阶数学严密推导提供了透明且可复现的验证基准。

Anthropic 发布 Claude Haiku 5.5：轻量级智能体与近零延迟端侧推理

大模型 智能体

Anthropic 正式推出 Claude Haiku 5.5。作为 Haiku 家族的最新一代轻量模型，新版本在编码执行、JSON Schema 严格约束以及工具调用吞吐方面提升显著，同时保持了极低的 Token 定价与首字延迟，专门针对自动化高频智能体工作流与开发者日常代码补全场景进行了深度对齐。

信源：Anthropic 官方发布 anthropic.com/claude-haiku-5-5 ↗

Robbie Tilton 开源 Compositor：纯 Swift 构建的 macOS 原生轻量设计工具

Apple 独立开发

开发者 Robbie Tilton 在 GitHub 开源了名为 Compositor 的全新 macOS 原生图像编辑与设计工具。软件完全采用 Swift 与 Metal 原生框架打造，不依赖任何 Electron 或跨平台框架，主打毫秒级冷启动、极致低内存占用与高保真矢量排版体验，被社区评价为 macOS 平台上兼具性能与美感的独立软件代表。

信源：GitHub Trending / macOS 精选 github.com/robbietilton/Compositor ↗

Docker 官方开源 Docker Agent：沙箱化容器级自动化编码执行环境

智能体 AI编程

Docker 官方团队在 GitHub 发布开源项目 docker-agent。该工具旨在为各类自主编程智能体提供安全、受控、快速重置的容器沙箱运行时，支持智能体在独立虚拟环境中安全执行任意 Bash 脚本、运行测试套件与调试依赖，避免本地机器文件系统遭受未知代码破坏。

信源：Hacker News / Docker 官方 github.com/docker/docker-agent ↗

NandhaKishorM 开源 Laya：单步前向非自回归多语言决策引擎

智能体 AI编程

开发者 NandhaKishorM 开源了专注快思考的系统一决策引擎 laya。与传统自回归逐步生成 Token 的模型不同，laya 支持在单次前向传播中完成结构化分类、评分与布尔判定，支持 100 多种语言，并配备智能动态路由器，能够将智能体系统的分类与路由延迟缩短至数毫秒级。

信源：GitHub Trending github.com/NandhaKishorM/laya ↗

Hugging Face 论文精选：图灵机与预言机视角下的智能体计算理论

智能体 大模型
