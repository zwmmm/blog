Anthropic 开启主动式个人助理 Claude Duet 预览测试：搭载独立云端虚拟机，无需提示词全天候自主运转

智能体 大模型

Anthropic 正式公布全新个人智能体产品 Claude Duet 并开启小范围预览测试。不同于等待用户单向输入 Prompt 的传统对话界面，Claude Duet 专为全天候主动服务设计。每个实例运行在独立云端安全沙盒虚拟机中，即便用户关闭电脑或离线，智能体仍可按照周期性策略自主巡检关联的邮箱、日历、云文档与项目看板，并在每天清晨输出结构化简报或在突发变动时主动推送预警。系统由 Claude Opus 5.5 驱动，针对高敏感操作设置了严格的真人确认拦截机制，标志着个人智能体由单次问答工具正式跨入常驻自主执行阶段。

信源：Anthropic 官方发布 claude.com/product/claude-duet ↗

DuckDB 2.0.0 LTS Cinnamon Teal 正式发布：内置 Quack 远程协议与原生 Agent 模式，历经近两万次提交

AI编程 独立开发

分析型嵌入式数据库 DuckDB 正式发布 2.0.0 长期支持版本（LTS），代号 Cinnamon Teal。该版本汇聚了自 1.5 以来近两万次代码提交，是该项目史上功能演进规模最大的一次里程碑。新版本完整实装了轻量高效的 Quack 远程网络协议与全局异步 I/O 引擎，引入一等公民级 VARIANT 混合半结构化数据类型与原生触发器支持。特别引人瞩目的是，2.0 增加了专为代码与数据智能体设计的内置 Agent 模式，优化了由大模型直接驱动的即时元数据自省与流式执行管线，为本地分析型智能体应用提供了极其坚实的计算底座。

信源：DuckDB 官方发布 duckdb.org/2026/10/21/announcing-duckdb-200 ↗

OpenAI 联合安全机构发起 Patch the Planet 行动：前沿安全智能体联动上游社区，两月协同修复 PHP 核心远程代码执行漏洞

大模型 智能体 AI编程

针对 AI 自动化漏洞挖掘工具可能被黑产滥用冲击开源软件生态的严峻挑战，OpenAI 宣布联合 Trail of Bits、Calif 与 HackerOne 发起 Patch the Planet 开源防御计划。该行动以安全推理模型为核心，配合资深安全工程师对模型发掘的高危隐患进行形式化验证、测试用例编写与补丁实现。在此次公布的 PHP2Shell 核心高危漏洞协同披露案例中，团队在漏洞对外公开前联合 PHP 基金会、云厂商与网络防御厂商建立了长达两个月的防御窗口，在零日威胁爆发前完成了静默全网加固，为智能体时代的开源协同披露树立了新标杆。

开发者推出 macOS 原生资源监控与智能体诊断工具 Vitals：以应用维度重构系统状态，原生集成 MCP 服务

Apple 智能体 独立开发

针对 macOS 自带活动监视器在面对现代开发工具与智能体集群时进程分散、排查繁琐的痛点，独立开发团队打造了轻量系统级监控工具 Vitals。软件改变了传统的孤立进程列表呈现方式，将数百个散落的后台子进程归拢至所属 App 树形视图下，清晰直观地展示各应用实际的 CPU、内存压力、GPU、传感器风扇与电池消耗。更关键的是，Vitals 内置了专为 Claude Code、Cursor 与本地智能体打造的 MCP 服务器，AI 助手可通过工具调用直接读取当前系统硬件负载、空闲开发端口与容器状态，让端侧环境诊断实现真正的自动化。

信源：少数派 / Vitals 官方 vitalsmac.com ↗

Simon Edwardsson 开源 360M 端侧终端世界模型 WorldTUI：底层无 Shell 与文件系统，纯模型实时预测字符光标演变

大模型 AI编程 独立开发

独立研究者 Simon Edwardsson 在个人博客公布并开源了端侧世界模型实验项目 WorldTUI。作者仅使用 3.6 亿参数微调出一个完全模拟终端控制台交互的世界模型。该系统底层没有任何真实的 Bash 解释器或文件系统，用户的每一次物理按键都会作为连续观察输入输入模型，由模型自回归预测整屏字符流的下一状态。实验展示了模型不仅能精准复现 Vim 语法高亮与 Tmux 分屏操作，还能在其隐空间中记住跨指令的上下文状态。该项目借助 WebGPU 实现了浏览器端毫秒级单步推断，生动展示了交互式世界模型颠覆传统软件执行范式的潜能。

信源：simedw.com / Hacker News simedw.com/2026/10/21/world-model-terminal/ ↗

Hugging Face 论文库首发 GUI 智能体世界模型验证器：以屏幕状态迁移守卫防范界面劫持与越权攻击

智能体 大模型

随着计算机使用（Computer Use）智能体深入操作系统接管人机界面，GUI 交互的安全性面临严峻挑战。来自顶尖科研团队的论文指出，现有的屏幕监视器仅判断单一屏幕画面的合法性极易被欺骗，点击登录按钮跳转登录页是正常操作，而在查看订单时弹出登录页则极可能是界面劫持钓鱼。论文提出了基于世界模型的迁移验证器架构，根据智能体的动作预先推演预期的界面状态变迁，并在真实环境响应与预测偏离时立刻熔断阻断操作。在多套复杂操作系统测试基准中，该方案成功拦截了绝大多数针对图形界面的混淆与提权攻击。
