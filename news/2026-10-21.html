DeepSeek 正式开源高并发生产推理框架 DeepInfer：集成 FlashMLA 与全套算子，支持 MoE 专家并行与 EPLB 极致吞吐

大模型 AI编程

DeepSeek 官方正式开源其支撑全球线上大规模核心生产服务的超高性能离线与生产推理引擎 DeepInfer。该框架首发针对 DeepSeek-V4.1-Flash 等旗舰模型提供端到端加速，底层原生整合了 FlashMLA、DeepGEMM、DeepEP 通信库、TileKernels 与 DeepSelect 算子库。框架支持 Attention 数据并行与负载均衡的 MoE 专家并行（EP 与 EPLB）、DSpark 投机验证与 SWA 有界重放，并搭载零开销异步批处理调度器与结构化输出引擎，彻底公开了万亿级混合专家大模型在大规模生产集群中的吞吐极限与工程调度机密。

信源：GitHub / Hacker News github.com/deepseek-ai/DeepInfer ↗

Cloudflare 联合开源 TypeScript 的 Rust 移植项目 tsrs：编译与类型检查提速 8 倍，内存占用降低 70%

AI编程 独立开发

针对巨型前端与全栈工程在冷启动、类型检查及边缘运行时构建中的漫长延迟，Cloudflare 官方宣布深度参与并开源 TypeScript 的纯 Rust 完整移植版 tsrs。相较于官方基于 Node.js 运行时的 tsc，tsrs 实现了高达 8 倍的编译与静态类型检查吞吐提升，同时将内存峰值占用大幅缩减 70%。该项目不仅可在边缘 Workers 运行时中实现毫秒级的即时类型验证与代码打包，还为独立开发者与大型 monorepo 项目摆脱漫长 CI 构建等待提供了开箱即用的现代化底层基建设施。

信源：Cloudflare Blog / Hacker News blog.cloudflare.com/typescript-rust-port ↗

Mistral 正式发布 Voxtral 3：首发跨 50 种语言的多模态语音智能体 SDK 与实时低延迟流式流水线

大模型 智能体

Mistral 官方发布全新全双工语音基础模型家族与多模态智能体框架 Voxtral 3。针对现有语音助手常面临识别卡顿、中断反应迟钝与复杂工具链编排断裂的问题，Voxtral 3 将端到端语音转写、多轮逻辑思考、外部工具调用与情感化动态语音合成（TTS）全部深度融合进单个低延迟实时流式管道，原生覆盖 50 多种语言。随模型一同释出的 Voice Agent SDK 提供了即时通话打断（Barge-in）、敏感词审查与多步业务工作流调度支持，并面向注重数据隐私的企业开放欧盟节点 API 与本地全量私有化部署。

信源：Mistral AI 官方发布 mistral.ai/news/voxtral-3 ↗

独立开发者推出纯净 Rime iOS 输入法「紫毫」：基于中州韵与端侧离线模型，无感同步 Mac 鼠须管

Apple 独立开发

针对 Apple 跨端用户在 Mac 上习惯使用开源鼠须管（Squirrel），而迁移至 iPhone 与 iPad 却被迫忍受带广告、上传剪贴板的商业输入法的长久痛点，独立开发者打造并上架了基于 librime 核心的中文输入法「紫毫」（Hare）。软件开箱内置雾凇拼音与 6.8MB 的本地端侧语法模型「紫毫口语」，支持触屏落点防误触纠错与小鹤双拼辅码筛选。更关键的是，紫毫支持直接订阅公开 GitHub 方案仓库并在手机沙盒内离线编译，个人词库通过 iCloud 与 Mac 鼠须管双向合并同步，所有击键运算完全停留在本地设备。

信源：少数派 / Hare 官方 hareime.com ↗

HumanLayer 发布 SlopCodeBench 2026 年 10 月编程智能体评测：过高推理预算反致上下文污染

AI编程 智能体

HumanLayer 团队联合学术机构更新了长程编程智能体压力评测基准 SlopCodeBench（SCB）2026 年第四季度实测报告。评测针对主流前沿大模型在多文件级真实重构任务中的代码洁净度与功能完整性进行深度检验。报告指出，随着各大厂商竞相推出超长思考（xhigh reasoning）配置，模型在面对实际代码库时反而出现了过度设计、臆造防御性冗余结构与上下文污染的负向效应（xhigh considered harmful）；相反，精细的上下文工程、分层提示词与确定性工具反馈才是决定长程自主编程成功的关键支柱。

信源：GitHub / HumanLayer github.com/humanlayer/advanced-context-engineering-for-coding-agents ↗

Hugging Face 论文库首发 HybridResearcher：跨越结构化 SQL 与非结构化网页的异构深度调研智能体

智能体 大模型

针对目前企业级自主研究智能体在处理跨域现实问题时容易偏科于单一数据源的结构性瓶颈，来自顶尖机构的研究团队在 Hugging Face 论文库发布了 HybridResearcher 框架。现实中复杂商业与技术决策往往需要同时跨越内部数据库的结构化精确计算与外部开放互联网的非结构化动态证据。HybridResearcher 引入了双轮驱动架构与异构证据仲裁器，能够自主将长程研究目标拆解为 SQL 执行管线与网络检索智能体集群，并在语义证据与确定性统计之间构建可验证的互证闭环，大幅削减了跨模态长程推理时的幻觉扩散。

信源：Hugging Face 论文库 huggingface.co/papers/2610.24899 ↗
