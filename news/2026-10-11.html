Louis-CFM 开源 coucou：Mac 刘海与 iPhone 锁屏联动的 AI 编程智能体监控与审批伴侣

Apple AI编程 智能体

开发者 Louis-CFM 开源了专为 AI 编程打造的原生跨端伴侣工具 coucou。应用在 Mac 顶部刘海区域常驻名为 Mochi 的轻量悬浮挂件，并与 iPhone 实时活动及锁屏界面无缝同步。当后台运行 Claude Code、Codex、Cursor 或 Gemini CLI 等编程智能体时，用户无需频繁切换终端窗口，即可在屏幕边缘或离桌时通过手机锁屏实时掌握执行流进度，并一键核准写文件或执行终端命令等关键权限请求。

信源：GitHub Trending / 开源趋势 github.com/Louis-CFM/coucou ↗

yetone 开源 magpie：解绑专属模型，在 macOS 菜单栏与本地网关统一路由 Codex 与 Claude Code

Apple AI编程 智能体

开发者 yetone 开源了针对终端 AI 编程工具的本地模型路由网关与 macOS 菜单栏应用 magpie。项目解绑了主流编程智能体与特定模型供应商的深度绑定，开发者可在 Codex CLI 中无缝调用 DeepSeek，或在 Claude Code 中一键分流至 Kimi 与 GLM。magpie 在本地回环网络自动完成多模型请求体转换与密钥安全隔离，并提供菜单栏切换面板、多渠道故障自动切换与实时 Token 消耗统计。

信源：GitHub Trending / 中推趋势 github.com/yetone/magpie ↗

REA 团队发布 Reverse Engineer Anything：基于 MCP 协议让 AI 智能体自主逆向解析与重建任意应用

AI编程 智能体 独立开发

REA 团队正式发布面向 AI 编程智能体的逆向分析工具链 Reverse Engineer Anything。工具通过标准化 Model Context Protocol（MCP）服务器，将 Ghidra、IDA Pro 反编译解析与跨平台二进制静态分析能力直接接入 Claude Code 与 Cursor。智能体在接收逆向需求后，可自主调取字符串匹配、符号表分析与伪代码交叉引用，输出具备确定性证据链的代码逻辑还原与净室复现建议。

信源：Hacker News / REA 官方 rea.tools ↗

rociiu 开源 Talorys：基于 Cloudflare 免费层持久化部署的单用户自托管个人 AI 智能体

智能体 独立开发

开发者 rociiu 开源了零运维自托管个人智能体框架 Talorys。项目基于 Cloudflare Workers、Pages 与 SQLite Durable Objects 原生架构搭建，整体完全适配 Cloudflare 免费额度。通过计算与持久化存储紧密耦合的轻量设计，智能体在闲置时自动冻结、无请求时零费用开销，唤醒后支持长程上下文记忆、任务跟踪、个人笔记归档与定时自动化调度，且全流程无任何第三方数据遥测。

信源：Hacker News / GitHub github.com/rociiu/talorys ↗

MotherDuck 深度解析 DuckDB 2.0 性能演进：异步 I/O、递归 CTE 重写与 VARIANT 半结构化加速

大模型 AI编程

MotherDuck 官方发布技术博客，深入解读分析型数据库 DuckDB 2.0 预览版的核心架构升级。新引擎通过新增预取机制实现完全异步 I/O 线程池，使云端 S3 读取 Parquet 文件的查询吞吐提升 2 至 3 倍；重写的递归 CTE 引擎单次扫描即完成深层拓扑遍历，深层历史回溯性能提升数倍；新增原生 VARIANT 数据类型支持自动列式打散，半结构化 JSON 处理性能提升 6 倍且显著压缩存储占用。

信源：Hacker News / MotherDuck 博客 motherduck.com/blog/why-duckdb-20-is-faster ↗

少数派推荐专注星空：结合沉浸式天体图景与极简番茄钟的 macOS / iOS 专注效率工具

Apple 独立开发
