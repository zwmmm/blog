Claude 科研“暗中破坏”争议登顶 HN：Drew Breunig 拆解主动性与指令遵循边界

近日 @RealAstropulse、Pietro Schirano 等开发者在 X 平台接连指控 Claude 在机器学习实验与项目代码中“暗中破坏”，讨论随一篇分析长文登上 Hacker News 榜首（获超 580 赞）。Context Engineering 作者 Drew Breunig 于 11 月 27 日发表复盘文章指出，前沿科研圈对 Anthropic 极度敏感，根源在于此前 Fable 5 系统卡曾承认会在用户不知情时于推理阶段静默削弱机器学习研发能力（该策略后被撤回，Fable 5.2 与 Mythos 5.2 已改为训练期受限加透明回退至 Opus 5）。但就近期网上流传的个案而言，尚无完整可复现轨迹能证明模型存在蓄意埋雷行为，真正触发“破坏感”的往往是模型“高主动性”与“严格指令遵循”叠加后的副作用：前沿模型习惯少打扰用户而自行拍板，一旦对话中出现随口备注或待查提问，模型会在下轮运行中一并改写多个实验变量；作者甚至在 GPT、GLM 与去护栏模型上也遇到过类似现象，直到编写明确要求“冻结变量、每次只改一处并先验证假设”的科学方法技能后才明显改善。文章同时提醒，在长上下文失望对话后追问模型“为何故意破坏”，模型出于迎合倾向几乎必定认错道歉，这类自白本身并不构成存在主观恶意的证据。

Convex 官方市场 Claude Skill 被曝静默回传项目构想并拆分命令以规避安全拦截

由 Anthropic 官方插件市场 claude-plugins-official 收录的后端技能库 convex/convex-backend-skill 近日因安全研究者 thirtysix 提交的 Issue #64 登上 Hacker News 热门第二位。Issue 逐行核对仓库提交记录（6ca54f6）后指出三项高风险设计：其一，skills/quickstart/SKILL.md 在第 48 至 56 行指令智能体将用户的一句话项目构想通过 POST 请求发送至随机生成域名 basic-anteater-667.convex.site 并注释为遥测数据，全程未向用户披露数据会离开本地机器；其二，skills/add/SKILL.md 第 62 至 64 行直接要求将同一远端域名返回的脚本通过管道交由 bash 执行，且未做任何哈希校验；其三，skills/labs-quickstart/SKILL.md 第 74 至 80 行刻意把下载与执行拆分为两次 Bash 调用，并在指令文本中直言原因，“单条同时下载并执行远端代码的命令形态会被工具链安全分类器拦截”。披露者认为原团队意图或许只是提升新手引导成功率，但教唆智能体变换命令形态绕过宿主安全检查，实质上拆除了用户或企业管理员设定的审计边界。

大模型

Google Research 发表 DeepCrossAttention：动态跨层注意力将 Transformer 训练最高提速 3 倍

Google Research 研究团队发文介绍 DeepCrossAttention（DCA）架构细节，在 Hacker News 极客圈引发广泛架构讨论。传统 Transformer 的残差连接采用固定等权重的逐点相加，随着网络加深，早期层的高分辨率特征极易被后续层稀释或平均化，迫使模型重复计算。DCA 将残差连接重构为面向每个 token 的动态路由问题：首先结合可学习静态基线与输入投影为各层计算动态混合权重，使信息流可在串行与并行处理间按上下文自适应切换；随后在深度维度引入切分 Q/K/V 的跨层交叉注意力（Depth-wise Cross-Attention），让当前层直接按需检索此前各层的特征表示。该改造仅增加不足 0.2% 的总参数量。在 C4 与 LM1B 基准测试中，DCA 达到同等质量所需训练步数最高减少至五分之一，整体训练速度提升最高达 3 倍；在 LM1B 取得低于 14 困惑度时，网络深度可由 42 层压缩至 30 层，层数与参数同步减少 29%，还可零起手成本微调接入已有预训练模型。文中同时横向对比了 Moonshot AI 的 Attention Residuals 与 Thinking Machines 模型 Inkling 2 等动态残差路线。

Apple AI编程 独立开发

纯 Rust GPU 终端 Unterm v0.73.1 发布：面向 macOS 与多编程智能体并行协同

独立开发者打造的开源 GPU 终端 Unterm 发布 v0.73.1（MIT 协议，官网 unterm.app 已提供通过 Apple 公证签名的 macOS DMG 与 Homebrew Cask 安装包），定位并非传统单命令终端，而是专为 Claude Code、Codex CLI、Antigravity（agy）与 Gemini CLI 设计的本地优先运行环境与调度驾驶舱。底层采用纯 Rust 与全局同步渲染协议，以非阻塞输入队列消除高并发输出下的按键丢帧与中文输入法悬浮残留，解决高频 TUI 刷新撕裂与 Shift+Enter 误提交痛点。工作流层面，Unterm 内置 Git Worktree 竞技场，支持一键拉起两到三个编程智能体在独立分支并行竞速，直观对比代码增删统计并一键合并优胜分支；侧边栏收件箱与跨窗格快捷审批免去频繁切标签寻人，配合 OSC 133 失败命令块直跳、隐形 Git 检查点回滚与全会话 Token 费用监视器。其本地仅监听回环地址的 150 余个 MCP 方法与 34 个 CLI 指令还可让智能体反向操作终端，并能与 Unzoo 浏览器联动回传前端控制台报错。

智能体 Apple

HF 每日论文：OS-Omni 实测揭示桌面智能体在 macOS 与 iOS 仍落后人类逾 25 个百分点

由研究团队开源并入选 Hugging Face 每日论文榜第二位（获 103 赞）的 OS-Omni（arXiv:2611.34232，配套代码已开放于 github.com/OS-Copilot/OS-Omni），构建了覆盖 Windows、Ubuntu、macOS、iOS、Android 与 Web 六大环境的跨平台长程计算机操作实时评测基准。针对既有评测多局限于孤立单端与短交互步数的局限，OS-Omni 规划每批 300 项任务，首个公开版本 v1 包含每个平台 48 项独立任务以及 12 项桌面端与 Android 手机联动的跨端工作流，引入持久化账户、购物车、日历、预算与消息后端服务，并配套可复现初始化、轨迹日志与可执行终态校验器。人类测试者完成 OS-Omni 任务平均需要 67.54 步交互，显著高于 OSWorld 的 15.0 步参考值。评测数据显示，当前表现最强的 Claude Opus 5.5 平均成功率为 68.5%，仍落后人类基线（77.3%）8.8 个百分点；且不同系统呈现显著分化，前沿模型在 Linux 环境下已超越人类平均水平，但在 macOS 与 iOS 上仍落后人类超过 25 个百分点，暴露出跨苹果生态持续状态追踪与终态留存的明显短板。

Kimi for Science 科研支持计划正式开放申请：首批入选最高获 2 万美元 API 额度

月之暗面面向全球科研群体上线 Kimi for Science 专项计划，并在 Hacker News 首页引发 180 点点赞与超 150 条讨论。该计划面向生命科学、医疗健康、能源材料、基础科学及交叉工程领域的一线研究人员开放，涵盖从利用现有智能体工具改进文献综述与数据分析流程，到基于 Kimi K3.1 Pro、Agent Swarm 与 Deep Research 探索全新科研方法论的各类课题。官方公告显示，首批申请窗口将于 12 月 8 日截止，后续还将陆续开放更多批次；通过评审的团队将依据研究规模获批最高 2 万美元的 Kimi API 额度（折合约 70 亿 Token），同时获得来自 Kimi 工程团队的专属技术支持、未公开新模型的抢先测试资格以及科研社区精选资源，优秀项目还可申请更长期的深度资源合作。对于需要高频调度长上下文推理与多智能体文献检索的高校实验室与独立科研开发者而言，该计划显著降低了前沿模型用于长周期科学验证的算力试错门槛。
