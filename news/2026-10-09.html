Cactus Compute 开源 Whistle：16.9MB 单文件纯 CPU 端侧语音转文本模型

智能体 大模型

Cactus Compute 正式开源轻量级端侧自动语音识别模型 Whistle。模型以仅 16.9 MB 的单文件发布，采用 CQ2bit 量化技术与 36M 激活参数，完全在普通 CPU 上流畅运行，无需 GPU 或云端网络。Whistle 支持 7 种语言的自动检测与毫秒级词级时间戳对齐，首字延迟仅 11 毫秒，并在清晰语音测试集上取得了优于标准 Whisper 的识别准确率，适合嵌入各类边缘设备与智能体实时输入流。

信源：Hacker News / Cactus Compute cactuscompute.com/blog/whistle ↗

storytold 开源 Photocraft：纯 Rust 与 wgpu 构建的开源图像处理工作台

独立开发 AI编程

开源组织 storytold 在 GitHub 正式开源项目 Photocraft。该项目采用纯 Rust 语言对经典图像编辑软件 Adobe Photoshop 进行了净室重构，底层基于 wgpu 框架实现高性能 GPU 渲染合成。Photocraft 完整支持 PSD 文件的双向读写与多种相机 RAW 格式无损解码，并内置原生 Model Context Protocol 控制协议，方便 AI 智能体通过自动化信道直接编排和操作图层。

信源：GitHub Trending / Hacker News github.com/storytold/photocraft ↗

DuckDB 官方发布 DuckLake：基于原生 SQL 与 Parquet 的现代化轻量数据湖

AI编程 独立开发

DuckDB 官方团队在 GitHub 发布开源数据湖规范与扩展 DuckLake。不同于传统依赖庞大 Avro 与 JSON 元数据目录树的方案，DuckLake 创新性地采用标准 SQL 数据库作为元数据目录，直接管理底层的标准 Parquet 数据文件。系统全面支持 ACID 事务安全、版本快照、表结构动态演化以及原生 SQL 时间旅行查询，大幅降低了中小团队与独立开发者构建分析型数据湖的维护门槛。

信源：Hacker News / DuckDB github.com/duckdb/ducklake ↗

rehan-remade 开源 Universal Modder：基于 Claude Code 的 PC 游戏全自动逆向工具链

AI编程 智能体

开发者 rehan-remade 开源了面向自主编程智能体的游戏修改套件 universal-modder。该工具集成了专用 Skills、逆向工程工具链以及 fal MCP 多模态资产生成桥接，使 Claude Code 能够自主分析 PC 游戏可执行文件、提取资源资产、生成 3D 模型与音频替换包，并自动注入补丁完成游戏内回归测试，展示了编程智能体在复杂二进制逆向工程与资产制作场景下的全流程协同能力。

信源：GitHub Trending / 开源趋势 github.com/rehan-remade/universal-modder ↗

Apple 独立开发

Hugging Face 论文精选：5000 万 Token 窗口下的智能体真实长程记忆架构

大模型 智能体

Hugging Face 今日推荐论文《Real Long-Term Memory for AI》提出了一种面向大语言模型智能体的新型持久化长程记忆系统。该研究突破了传统反复重计算全量键值缓存的高昂成本瓶颈，构建了支持高达 5000 万 Token 上下文的高速外部键值检索与增量融合机制，在保持极低推理延迟的同时实现了跨多轮会话的精准事实回忆与连贯推演。
