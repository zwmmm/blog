Anthropic 推出消息线程（Message Threads）：首字生成延迟降低 35%，专为 Claude Code 与长时间运行智能体优化

智能体 AI编程

针对长时间运行的编程智能体在多轮交互中频繁重发完整历史导致延迟陡增的痛点，Anthropic 正式在 Messages API 中推出“消息线程”（Message Threads）公开测试版。在该机制下，智能体无需在每一轮请求中重复上传全部历史对话与工具执行结果，仅需提交增量内容与前前回调 ID。在 50 万至 100 万 Token 的长上下文测试中，首字生成时间（TTFT）中位数降低约 35%。该特性已在 Claude Code 中默认开启，并通过端到端加密内存缓存保障数据隔离，不仅大幅降低长程开发交互延迟，更彻底免去了“计算机使用”（Computer Use）多模态智能体重复回传大尺寸屏幕截图的开销。

研究团队提出“权重空间编程”范式：大模型可免梯度直接读写神经网络权重，修复 Qwen 缺陷使数学推理翻倍

大模型 AI编程

在 Hacker News 引发全网极客热议的前沿研究《Sparks of Weight-Space Programming》指出，前沿大语言模型已具备直接读写与推理神经网络权重的先验能力。在完全不借助梯度反向传播与环境反馈的前提下，模型仅通过解析 1.7 万个原始权重即可推断训练任务目标。实验中，GPT-6 Astra 针对 Qwen3.5-0.8B 模型卡片所警示的推理循环死锁缺陷，直接在参数空间中精准定位并改写了 0.016% 的特定权重。在保持相同采样超参的评测下，这一无需训练循环的权重编辑使模型在 MATH-500 上的得分从 7.9% 跃升至 48.1%，指令遵循能力（IFEval）提升 3 倍，证实了“由大模型直接推理并手术式修正参数”的全新优化范式。
