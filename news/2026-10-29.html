Google DeepMind 正式发布 Gemini 4 Carbon：登顶智商评测榜首，主打前沿安全防御与长程智能体推理

大模型 智能体

Google DeepMind 正式推出全新前沿旗舰大模型 Gemini 4 Carbon。该模型在最新更新的 Artificial Analysis 智商指数 v5.0 榜单中以 59 分高居全球第一，在复杂的长程任务规划、多步骤自动化执行与高质量代码生成上取得实质突破。Carbon 特别强化了系统安全防护能力，在 SEC-bench Pro 漏洞挖掘测试中达成 88.2% 准确率，在 ExploitGym 与 CWE-bench 补丁修复基准测试中分别达到 54.8% 与 71.0%，显著降低了高强度生产代码环境下的模型幻觉与偏离率。作为两周前发布的 Gemini 4 Argon 的深度升级，新模型为企业级自主智能体编排与安全代码审计提供了全新基座。

Flamerix AI 揭秘 Claude Code 隐藏消耗：每隔半分钟发送完整会话生成三词状态行，静默吞噬近两成 Token 预算

AI编程 智能体

安全与性能监测机构 Flamerix AI 在 GitHub Gist 披露针对 Claude Code 的排查报告。分析人员在分析 OpenTelemetry 请求指标时发现，Claude Code 会对所有后台智能体每隔约 30 秒将完整长上下文 Transcript 发送给 Opus 模型，仅为生成一句简短的 3 至 5 词动作状态摘要展示在界面中，而该摘要甚至不参与模型核心推理。该隐性请求在典型开发场景下占到全部 Token 支出的 16.4%，甚至超过部分主对话调用量。目前官方尚未提供关闭配置项，社区已提供基于 Bun 预加载钩子的本地热补丁方案，彻底阻断无效请求并大幅节省用量。

极客项目 Qwenputer 登顶技术热榜：将 RISC-V 确定性 CPU 编译进 Qwen3.5 权重，以内置 RNN 状态免工具执行 C 与 MicroPython

大模型 AI编程

独立研究者 Divyansh Agrawal 推出实验性前沿项目 Qwenputer。作者突破性地将一套完整的 RISC-V 架构 CPU 编译进开源模型 Qwen 3.5 4B 的权重中，巧妙利用该模型每四个注意力层中三个采用的 Gated DeltaNet 线性循环神经网络（RNN）结构，通过固定门控衰减为 1 将状态矩阵转化为高精度 RAM 内存。模型在前向推理计算中即可严格确定性地执行指令流水线、C 语言和 MicroPython 程序，彻底消除了外部 Python 沙箱或 Function Call 工具调用的延迟与环境开销，为神经网络权重深度融合符号计算提供了全新范式。

信源：Divyansh Agrawal 个人博客 / Hacker News divagr.com/blog/qwenputer ↗

yetone 开源 macOS 菜单栏智能体中枢 Magpie：统一调度全平台 AI 编码工具，无缝接驳多模型网关与额度故障转移

Apple AI编程 中推

上海交大联合团队提出智能体服务联合调度框架 TAO：打通 GPU 推理与工具调用瓶颈，端到端延迟降低 26%

智能体 AI编程

上海交通大学与斯坦福大学研究人员在 Hugging Face 论文库发布智能体集群调度系统 TAO（Tool-Aware Joint Scheduling）。针对当前大模型智能体在 GPU 神经网络推理与 CPU 外部工具调用之间频繁交替、导致 GPU 计算单元大幅空转与会话排队膨胀的难题，TAO 引入了感知工具返回就绪状态、结合时间衰减的节点级缓存积分以及显存占用动态规划算法。在涵盖 12 种真实工作负载与高并发测试中，TAO 将智能体服务整体延迟降低最高达 26.8%，首字延迟（TTFT）缩减达 36.3%，解码吞吐提升近三成，大幅提高了大规模智能体部署的吞吐性价比。

信源：Hugging Face 每日论文 / arXiv huggingface.co/papers/2610.37230 ↗
