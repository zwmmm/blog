Expo 正式开源全平台框架 Exact：一套代码原生覆盖 macOS 与移动端，首创面向 AI 智能体的闭环编译与交互测试

Apple AI编程 智能体

知名跨平台技术生态 Expo 正式开源全平台新一代原生框架 Exact。该项目主打「一次编写，原生随处运行」，全面原生支持 Web、macOS、iOS 与 Linux。与传统跨平台框架不同，Exact 首度将 AI 编程智能体（Coding Agent）作为一等公民级对象纳入系统设计，内建了专用的无头控制与视象反馈接口。终端智能体如 Claude Code 能够直接依据代码库自主拉起 macOS 或 iOS 模拟器、读取屏幕界面渲染结果、分析测试崩溃日志并完成自适应代码修复。官方指引中专门给出了面向智能体端到端自主开发的标准提示词协议，标志着客户端开发框架从「人类编写」向「人机共生协作」的底层范式跃迁。

德国安全团队披露 Lovable 重大越权漏洞：AI 生成应用暴露 15.9 万项目未授权访问，超 20 万私信与护照证件遭泄露

AI编程 大模型

德国独立网络安全研究机构 Crissy Field 发布针对当前热门的 AI 全栈生成平台 Lovable 的深度审计报告。团队对平台上由普通用户通过「Vibe Coding」方式生成的 159,041 个 Web 应用进行抽样扫描，发现因底层 Supabase 行级安全策略（RLS）缺失与默认鉴权配置机制缺陷，存在极其严重的对象级越权漏洞（IDOR）。外部人员无需任何身份验证，即可轻易遍历并调取项目数据库底层所有字段，已证实泄露超过 20 万条未加密的私信记录、企业内部合同、病历文档以及大量高清护照与身份证件扫描件。该事件为当下盲目依赖大模型端到端自动化生成应用、忽视底层安全合规防御的独立出海热潮敲响了严肃警钟。

开发者开源 190 行纯 JAX 版 DeepSeek-V3：零高级框架依赖，完整复刻多头潜在注意力与 MoE 路由架构

大模型 AI编程

机器学习研究者 Vaibhaav Tiwari 在 Hacker News 与 GitHub 同步开源了 deepseek-v3-jax 项目。作者完全摒弃 PyTorch、Flax 与 Equinox 等高阶抽象库，仅依赖底层纯 JAX 原语，用极其精简的 190 行 Python 代码从零复现了 DeepSeek-V3 完整模型架构。该实现严格对应 DeepSeek-V3 官方技术报告中的数学规范，完整覆盖了 MLA（多头潜在注意力）的键值低秩压缩与 RoPE 解耦投影，以及 DeepSeekMoE 的细粒度专家路由与无辅助损失负载均衡机制。权重参数全部采用透明的纯字典结构存储，作者在轻薄本 MacBook Air 上使用公有领域侦探小说从头跑通了预训练与自回归推理闭环，为社区极低门槛透彻拆解前沿大模型底层张量流转提供了清晰透彻的白盒范本。

开源自动化中台 Agent Autoloop 发布：终结 Claude Code 终端人肉守候，后台长程自运转与卡片轻量确认

智能体 中推 AI编程

针对当前开发者在使用 Claude Code、Codex 等命令行智能体时必须人肉盯守终端窗口的困境，国内独立开发者开源了轻量级智能体调度自动化中台 Agent Autoloop。该项目核心仅由数百行零外部依赖的代码构成，可无缝托管本地或服务器端 CLI Agent。当智能体执行大范围多文件重构或测试驱动跑批时，Autoloop 将在后台静默跟进任务全生命周期与异常自动恢复；仅在智能体遭遇代码分支重大决策、不可逆文件破坏或外部环境鉴权时，才会通过飞书、钉钉或 Telegram 主动推送富交互卡片请求人类拍板。这种平时不打扰、关键时刻拍板的异步双轨协同方案，在中推与独立出海开发者圈引发了热烈反响。

极简跨平台容器运行时 Kiri 开源：原生适配 macOS 架构，无缝平替 Docker Desktop 并内置免费隧道穿透

Apple 独立开发

独立开发团队正式开源轻量级跨平台容器运行时 Kiri，直指 macOS 开发者长期承受的 Docker Desktop 内存占用过大、电池消耗显著与后台守护进程繁杂等顽疾。Kiri 基于 Apple 原生 Virtualization 框架与轻量级 Hypervisor 进行深度重构，在保持与标准 docker CLI、Docker Compose 及 buildx 规范完全兼容的前提下，实现瞬时冷启动与极低闲置 CPU 占用。此外，Kiri 针对独立开发者在本地测试 Web 应用或调试 Webhook 回调的日常需求，创新性地内建了免费的一键式内网安全穿透隧道，无需安装第三方代理即可对外暴露临时公网访问域名，为个人开发者和独立全栈工程师提供了兼具极致性能与开箱即用的工作流体验。

Hugging Face 论文精选 MixUA：首创面向多用户与多智能体协同进化的多粒度记忆提炼架构，隐私泄露率低至 0.02%

智能体 大模型

随着自我演进型（Self-Evolving）智能体在复杂生产环境落地，如何在多用户、多异构智能体群组间共享技能经验与轨迹记忆，同时杜绝用户私密数据跨域泄露，成为学术界与工业界的前沿挑战。由顶尖研究机构联合推出的最新论文提出首个通用的多粒度记忆提炼系统 MixUA。该架构将异构智能体的自主探索轨迹提炼为经验教训，并动态划归至用户-智能体对、单用户私有、单智能体私有与全局公有四级作用域。在包含 5 位人类用户与 7 个异构智能体的 CrossLearnBench 基准测试中，MixUA 使跨用户多任务成功率相较无记忆基线提升 16 个百分点，同时在严苛的隐私探针探测下将私有数据越权暴露率压低至 0.02%，为构建安全的企业级群体智能进化网络奠定了理论基石。
