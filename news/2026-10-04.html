Aleph Alpha 发布开源 MoE 推理模型 Kolibri-1：总参 78B 激活仅 3.5B

德国老牌 AI 机构 Aleph Alpha 遵循 Apache 2.0 协议开源了欧洲主权大语言模型 Kolibri-1。该模型采用细粒度 MoE 架构，总参数量 78.1B，每 token 仅激活 3.46B 参数。其每层配备 384 个专家并由路由分配 6 个专家协同计算，支持最高 1M 上下文窗口。模型权重已完整同步至 Hugging Face，原生提供高质量双语推理、工具调用与长文本检索能力。

来源链接：https://aleph-alpha.com/en/blog/kolibri-has-landed-a-sovereign-open-weight-model/

Anthropic 发布 Claude Code 进阶实践：深度解析 Opus 5.5 在架构迁移与子智能体协作中的调度机制

Anthropic 针对旗舰模型 Claude Opus 5.5 在终端编程工具 Claude Code 中的应用发布了深度工程指南。文章详述了 1M 上下文在超大规模代码重构时的上下文裁剪与分层缓存读取策略，介绍了三层深度嵌套子智能体（Subagents）的职责隔离，并给出了通过 Claude Mods 定制化拦截工具调用、注入私有规范的具体实践方案。

来源链接：https://claude.dev/blog/getting-the-most-out-of-opus-5-5/

经典任务管理软件 2Do 现代架构重构：原生多窗口与日程负载可视化

老牌 GTD 任务管理工具 2Do 针对 macOS 与 iOS 平台推出了全面重构版本。新版本彻底告别早期密集排版，采用极简现代的三栏式布局与原生独立多窗口设计，加入了根据日程密集度动态呈现热力图的 Busy Days 视图。应用依然保持无需专属服务器的数据主权设计，支持 iCloud、CalDAV、Dropbox 以及与苹果提醒事项的双向同步。

来源链接：https://sspai.com/post/115166

开源消费级 MoE 推理引擎 Strata：单卡消费级 GPU 畅跑 125B 稠密路由大模型

开发者 Niko1221 开源了本地大模型推理引擎 Strata，专门解决消费级硬件运行大参数量 MoE 模型时的吞吐瓶颈。Strata 针对单张消费级显卡搭配内存与 NVMe 存储设计了高效的分层卸载与专家动态调度算法，原生提供兼容 OpenAI 与 Anthropic 规范的本地 RESTful API 服务，大幅降低了开发者在本地私有化部署前沿大模型的硬件门槛。

来源链接：https://github.com/Niko1221/Strata

智能体逆向改模工具 universal-modder 开源：让 Claude Code 自主探索与生成游戏 Mod

开源项目 universal-modder 结合 MCP（模型上下文协议）与多模态生成接口，为 Claude Code 等终端编程智能体扩展了游戏逆向工程与 Mod 开发能力。工具包含引擎特征侦测、反编译逻辑解析、修改脚本构建以及通过 fal 接口生成游戏格式贴图和三维资产的整套工作流，实现了从自然语言诉求到游戏内 Mod 实测的全自动化开发闭环。

来源链接：https://github.com/rehan-remade/universal-modder
