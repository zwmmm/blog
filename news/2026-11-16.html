Scott Hanselman 推出 GPU 终端监视器 gputaskman：支持 Apple Silicon 与 PC 深度透视显存与 KV Cache

AI编程 大模型

知名极客与微软资深开发者 Scott Hanselman 开源了面向本地硬件的 GPU 终端监视工具 gputaskman，被社区誉为“GPU 版 htop”。传统任务管理器只能给出显存占用的粗糙数值，难以解释具体资源流向；gputaskman 原生支持 macOS（Apple Silicon 统一内存架构）以及 Windows 与 Linux，能够深入进程底层，实时将显存消耗精确映射至具体大模型权重、KV Cache 缓存、系统运行时以及图形渲染模块。对于在本地 Mac 或 PC 上频繁运行大模型微调、量化推理与多 Agent 并发的极客而言，该工具提供了不可替代的硬件洞察力。

智能体 大模型

Hugging Face 每日论文榜重点推介前沿研究《WorldDraft: If Code Builds the World, Can Video Models Just Render It?》（arXiv:2611.16217）。针对当前世界模型在生成长视频时频发物体形变、重力失真与因果逻辑断裂的问题，研究团队提出了解耦架构：由多模态代码智能体负责构建精确的 4D 物理仿真与几何代码逻辑，而将视频大模型降维为纯粹的“生成式渲染管线”。实验表明，通过先由代码确定物理因果约束再由视频模型上色渲染，生成场景在长期交互中的物理因果一致性相较传统端到端生成提升 3.2 倍，开辟了代码智能体与物理模拟融合的新路径。
