Cloudflare 宣布收购 Deno：推进 Workers 融合，JSR 迁移至全球边缘网络

AI编程 大模型

Cloudflare 与 Deno 官方联合宣布达成收购协议，Deno 全体核心团队将加入 Cloudflare，推动 Cloudflare Workers、Durable Objects 与 Deno 在下一代 celld 架构上的深度融合。独立 Deno 运行时将继续获得一年的安全维护并保持开源，Deno Deploy 计划在未来半年内停运，而 JSR 现代包注册中心的基础设施将整体平移至 Cloudflare 全球网络，为全栈开发与智能体边缘部署提供更强大的底层支撑。

信源：Hacker News / Deno 官方博客 deno.com/blog/cloudflare ↗

Franz Enzenhofer 开源 big-arrow-on-the-screen：让 AI 智能体在 macOS 屏幕直观绘制高亮指引

智能体 Apple

开发者 Franz Enzenhofer 开源了专为 macOS 桌面端打造的轻量屏幕标注工具 big-arrow-on-the-screen。该工具既可作为快速命令行指令运行，也能作为 Agent Skill 供 Claude Code 与 Codex 调用。多模态智能体在执行端侧 GUI 自动化与跨应用协同流程时，可直接在屏幕任意坐标绘制大箭头、高亮框与悬浮说明，且窗口原生支持点击事件穿透，显著提升了计算机操作（Computer Use）类智能体在桌面端的可解释性与人机交互体验。

信源：Hacker News / GitHub Trending github.com/franzenzenhofer/big-arrow-on-the-screen ↗

shihabal3amri 开源 DiPlay：免外挂盒子与越狱，Android 车机原生运行 Apple CarPlay

Apple 独立开发

独立开发者 shihabal3amri 开源了针对 Android 车机（如比亚迪智能座舱等）的纯软件 CarPlay 接收端应用 DiPlay。项目无需任何第三方 USB 转接盒、无需 Root 越狱，亦不依赖外部云端鉴权服务器，直接基于车机原生通信协议栈实现了有线与无线 Apple CarPlay 的低延迟握手、高帧率画面投射以及方向盘多功能按键映射，为汽车车载软件的极客改造提供了优雅的开源范例。

信源：GitHub Trending / 开源趋势 github.com/shihabal3amri/DiPlay ↗

Anyway.FM 团队推出 Anyway.Fonts：更适合中文排版的在线字体即时预览与缺字检测工具

Apple 独立开发

知名设计播客 Anyway.FM 团队推出了专为中文排版优化的轻量 Web 工具 Anyway.Fonts。工具针对中文多字重字体在不同尺寸下的行气、字间距与排版灰度进行了针对性调优，支持多段即时文本对比与自定义排版样式，并提供了一键扫描生僻字、标点符号缺失及系统回退方块（To-def）的功能，帮助前端工程师、独立开发者与排版设计师高效完成字体选型与兼容性自查。

信源：少数派 SSPAI / 独立开发 anyway.fm/fonts ↗

AI编程 智能体
