OpenAI 推出常驻智能体架构 Dots 与 GPT 6.1 Sol：探索长周期主动调度

OpenAI 正式公开常驻智能体系统 Dots 与高性价比推理模型 GPT 6.1 Sol。Dots 改变了单次单轮对话唤醒的被动模式，支持智能体在后台环境长周期保持监听与异步任务推进，依据外部事件与系统状态主动发起调度；配合仅为旗舰模型五分之一推理开销的 Sol，显著降低了常驻智能体多实例运行的算力门槛。

官方公告：https://openai.com/index/introducing-dots/

Magpie：面向 macOS 菜单栏的多模型智能体路由与 API 中继工具

独立开发者开源 macOS 原生菜单栏智能体路由中枢 Magpie。该工具专为 Claude Code、Codex 等各类命令行与桌面编码智能体打造，常驻 macOS 状态栏，支持将不同编程智能体的请求透明中继并按需路由至 DeepSeek、Kimi 等多种上游推理模型，解决多端代码智能体模型切换与本地密钥分散管理痛点。

项目仓库：https://github.com/yetone/magpie

Self-Play Search Distillation：基于自我博弈搜索蒸馏提升模型推理能力

Hugging Face 每日论文榜前列发布长链推理增强研究。论文提出基于自我博弈的蒙特卡洛树搜索（MCTS）蒸馏方案，针对高质量推理数据稀缺难题，让模型在探索过程中自主生成多分支竞争路径并评估决策后果，使轻量模型在无需庞大人工标注的前提下显著提升复杂逻辑与代码任务的推理鲁棒性。

论文链接：https://arxiv.org/abs/2609.30936

Unreal-Agent：面向高并发多智能体协同的轻量级异步调度 Harness

GitHub 高星开源项目 Unreal-Agent 发布。该项目采用 Go 语言构建了专为异步设计的智能体 Harness，提供进程间非阻塞事件流、结构化 Tool Call 沙箱与轻量级上下文压缩机制，单节点可稳定支撑数百个后台代码智能体并发执行复杂分支任务。

项目仓库：https://github.com/unreallabsai/unreal-agent

AIHOT：基于多源抓取与语义精选的主动式热点日报开源框架

中推圈与独立开发者热议自动化热点聚合框架 AIHOT。项目通过集成 RSS、Hacker News 及社交媒体的多源清洗引擎，结合大模型自动化评分与结构化排版流水线，实现无需人工介入即可每日定时生成高干货密度行业日报与静态站点部署，展现了个人开发者构建垂直资讯站的自动化新模式。

项目仓库：https://github.com/KKKKhazix/AIHOT
