大模型

OpenAI 首席科学家披露预训练核心基质：对数困惑度演化全貌与行业自律“速度红线”提案

OpenAI 首席科学家 Jakub Pachocki 正式发表长篇研究报告《Perplexity and Intelligence》，首席执行官 Sam Altman 称其为该机构历来最重要的公开定调之一。报告首次透明公开了 OpenAI 从 GPT-3.5 到最新前沿模型的内部对数困惑度（log-perplexity）收敛曲线：在严格隔绝的固定测试集上，GPT-3.5 约为 0.99，具备多步推理能力的 GPT-4 下降至 0.91，而近期前沿模型已跌破 0.8 并持续下探至 0.76，在这一压缩区间内模型在高级数学与复杂漏洞逆向等任务上展现出剧烈的非线性能力跃迁。Pachocki 论证指出，预训练阶段的文本压缩能力依然是模型通用智能最本质的底层基质，且缩放定律尚未遭遇瓶颈。为此，OpenAI 正式向全球前沿实验室提出倡议：将困惑度作为可量化的行业公认标尺，各机构应在安全监控与行为对齐技术未达到对应安全水准前，自愿签署设定不突破特定困惑度阈值的阶段性“速度上限”，以确保超人类智能的平稳可控演进。

02
智能体 AI编程

Hugging Face 论文精选：零幻觉、免文本生成的 System 1 确定性本地智能体架构

针对医疗与临床高敏场景中大模型云端推理隐私泄露、端侧小模型严重幻觉及错误链式传播的痼疾，Hugging Face 每日论文榜精选前沿成果《System 1 agents: a method for local, reliable and fast agentic AI》（arXiv:2611.21053），开创性地提出了免自回归文本生成的“系统 1”（System 1）智能体框架。该系统通过确定性编译器，将各类 API 工具的 Schema 定义及用户输入请求实时转译为基于严格候选约束的选择题决策树，再由紧凑的端侧单遍决策模型（One-pass Decision Model）直接输出结构化参数调用。在面向 157 项生物医学专用工具的 1952 次复杂真实请求测试中，System 1 智能体取得了 97.0% 的工具选择与正确拒绝准确率，大幅领先各类端侧大模型智能体方案（最高仅 95.2%）；在总计 6056 个关键参数填充中准确率达 97.0%，最核心的是实现了调用参数的“零虚构、零幻觉”，彻底规避了传统 LLM 常见 5.5% 至 19.7% 的幻觉污染，为高可靠端侧私有 Agentic 部署开辟了新路径。项目代码已在 GitHub 完全开源。

AI编程 智能体

Jane Street 开源内部 Agent 技能库：以统一规范赋能代码智能体与苏格拉底教学

全球顶尖量化对冲与技术机构 Jane Street 正式将其内部日常使用的高频 Agent 技能库对外开源（janestreet/agent_skills），上线即斩获超万星关注。该项目完全遵循业界标准的 SKILL.md 规范，旨在与各类现代编程智能体无缝对接。仓库首期完整公开了核心模块 socratic-tutor（苏格拉底导师）：通过内置严格的状态机控制与分级技能树（0 至 5 级），将智能体规范为严谨的个性化教学系统，摒弃直接倾倒答案的传统交互，而是通过分步诊断、单题提问、间隔复习与终极测评等递进式闭环引导开发者吃透硬核工程与数理知识。Jane Street 团队表示，开放该工程旨在分享工业级真实环境下经过严苛验证的 Agentic 指令工程与规范范式，为智能体上下文协议化标准化提供可落地的高质量范本。

智能体 AI编程

极客逆向反转爆款 Worker 755：人类成为大模型调度器的受限 Subagent

独立开发者 Gulivan 在 Hacker News 与 GitHub 上线了一款极具黑色幽默与前沿 Agentic 洞察的开源网页模拟终端游戏《Worker 755》（gulivan/worker755）。游戏巧妙颠覆了人机协同关系：玩家并非智能体的主人，而是作为真实大模型（可接入 Claude、GPT-4o、Gemini 等）在本地派生的“人类受限子智能体（Subagent）”。AI 管理器拥有全局任务看板并给玩家下发终端指令，玩家必须在 90 秒倒计时内输入 shell 命令并返回执行结果或事故报告。与此同时，雇佣 AI 的人类雇主 Dan 正在旁观聊天窗口，其私人家庭照片、机密 NDA 协议与关键文稿全存放在该主目录下，随时面临误操作被删除的风险。AI 管理器会对玩家的执行结果进行严苛审计并生成绩效考评报告。该项目不仅构思精巧，更生动映射了当代多智能体编排（Multi-Agent Swarm）中任务解耦、容错机制与权限越权等深刻的工程现实。

AI编程 Apple

Expo 官方重磅发布全平台框架 Exact：以 Agent Native 理念重构原生多端闭环

移动与全栈开发领军团队 Expo 正式发布了专为现代 AI 智能体时代设计的全新跨端全平台应用框架 Exact（expo/exact）。与传统为了跨平台而牺牲各端特性的“最小公倍数”折中方案不同，Exact 坚持“在每个平台以原生标准达到极致”的原则，在 Web 端输出原生真实 DOM、iOS 输出原生 UIKit、macOS 输出原生 AppKit，在 Android 输出原生 Material 3 与硬加速视图，兼顾 Linux 与 Windows 原生渲染。Exact 确立了三大核心基石：一是“Agent Native”，所有框架接口、构建机制与运行状态均从底层为代码智能体量身定制，使 Agent 能够在一个确定性的统一反馈循环中自动构建、启动、视觉感知、操作和断言验证多端应用；二是极致性能指标，确保应用具备 100 毫秒冷启动、100 毫秒热重载刷新，首屏前零应用 JS 开销，以及仅约 20KB 的超轻量 Web 运行时；三是绝对不作妥协的底层原生控制能力，为 AI 辅助编程时代的多端应用研发树立了新标杆。

Apple 独立开发

独立开发者打造精品工具浮屏 Floato：端侧 AI 自动化将零碎截图化为灵动岛与锁屏实时卡片

独立开发者 Nezuko 在少数派分享并上架了其历时数月独立打磨的 iOS 原生精品小而美工具「浮屏（Floato）」。该应用的灵感源自开发者在日常夜跑购买饮品时，频繁切入各种小程序查看取餐码的琐碎繁琐痛点。浮屏创新性地结合 iOS 本地 Vision 与端侧轻量 AI 视觉识别能力，用户只需对取餐码、快递取件码、电影票、高铁车票、登机牌或团购券截一张图，应用即可自动在后台离线解析出核心状态与时间信息，并将其转化为适配当前场景的精美动态卡片，无缝呈现在 iPhone 的锁屏界面、灵动岛（Dynamic Island）和桌面实时活动（Live Activities）之中。应用完全坚持本地离线化数据处理与苹果原生人机交互设计规范，无需复杂设置即可实现“随手一截、抬手即看”，展现了独立出海开发者深挖原生系统底层交互细节的极客匠心。
