robbietilton 开源 macOS 原生图形设计工具 Compositor：轻量极简的 Photoshop 原生替代方案

开发者 robbietilton 在 GitHub 开源专为 macOS 打造的原生图形设计软件 Compositor。该项目采用 Swift 与 Metal 原生开发，摒弃臃肿的跨平台框架，带来瞬时启动与流畅的图层渲染体验。Compositor 专注于核心位图编辑、非破坏性滤镜与矢量排版，为追求小而美工具链的 Mac 创作者与独立开发者提供了极简高效的本地工作台。

tamaratran 开源 fast-jev-compaction：基于单次决策模型的 Claude Code 上下文智能压缩插件

针对终端 AI 编程工具在多轮交互中上下文快速膨胀的问题，开发者 tamaratran 开源了 Claude Code 插件 fast-jev-compaction。该插件引入快速非自回归决策模型替代传统的大模型总结式压缩，在单次请求中精准评估历史工具调用与输出的有效性，剔除失效中间态的同时完整保留关键代码与指令上下文，显著降低 Token 消耗并维持长任务记忆精度。

来源链接：https://github.com/tamaratran/fast-jev-compaction
