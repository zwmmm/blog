大模型 智能体 AI编程

PrismML 发布 Ternary Bonsai 2.5 27B：5.9GB 三值模型补齐端侧智能体编程能力

PrismML 正式推出开源三值权重语言模型 Ternary Bonsai 2.5 27B，基于 Qwen3.8 27B 进行极致三值量化压缩，在仅占用 5.9 GB 内存空间（约每权重 1.76 bit）的前提下，重点攻克了前代小体积模型在多轮工具调用与长程代码代理任务中容易出现的过度思考、循环卡死与状态漂移难题。实测数据显示，Bonsai 2.5 27B 在 SWE-bench Verified 上的得分从上一代的 60.8 跃升至 75.6（逼近全精度基座的 80.6），DeepSWE v1.1 从 0 提升至 27，AppWorld 从 51.2 大幅提升至 90.5，在多轮交互评测 τ³-Bench 上以 73.9 反超全精度原版模型的 72.8。模型权重遵循 Apache 2.0 协议开放，原生支持通过 MLX 框架部署于 Mac、iPhone 与 iPad 等 Apple 设备，并可通过 llama.cpp 运行于消费级显卡，在单张 H100 与 RTX 4090 上分别实现 291 tokens/s 与 204 tokens/s 的生成速度。

02
大模型 AI编程

OpenAI 发布 GPT-6 科学研究进展：仅凭通用推理与代码完成湿实验级蛋白质设计

OpenAI 公布最新科学预印本《GPT-6 as a Universal Foundation Model for Protein Biology: Beyond Specialized Models》，首次在湿实验中证实 GPT-6 系列通用模型（包含 GPT-6.2）无需调用任何专用生物计算模型，仅依靠自身推理能力与通用编程工具即可直接生成全新的蛋白质三维构象及对应氨基酸序列。研究团队通过自然语言提示指定靶点结合区域与预期结构形态，模型在思维链中自主调用数学、物理、化学与生物结构知识并编写分析脚本筛选方案。在生物技术公司 Onava 执行的实验室合成测试中，GPT-6.2 设计的多组小分子结合蛋白在五个不同靶点上均测得结合活性，重设计的抗体互补决定区也保留了原有靶向结合能力，展现出通用大模型借助代码工具链直接切入硬核生命科学工程的跨界潜力。

03
智能体 AI编程

Anthropic 推出 Claude Ship：用 PR Steward 与策略审批打通代码提交后的合并闭环

针对代码智能体大幅加快开发速度后，Pull Request 提交之后的审查、返工与排队合成为工程团队新瓶颈的痛点，Anthropic 正式发布集成于 GitHub 的自动化交付套件 Claude Ship。该套件整合了已全面开放的 Code Review 与处于 Beta 阶段的 PR Steward、Claude Approvals 两大新智能体。其中 Code Review 负责多维度深度审校并对检出问题进行对抗性验证，Claude Code 内部团队自 6 月至 9 月启用后周均合并 PR 数量翻倍且回滚率降低超 40%；PR Steward 专职监听审阅反馈、修补 CI 失败与处理分支冲突，并在设计上严格禁止越权合并；Claude Approvals 则依据仓库中的策略文件自动判断低风险变更并给出审批，同时保留敏感模块的人工签字门槛，开发者亦可直接在 Claude Code 终端通过 /ship 命令一键托管从开 PR 到修复待合的全程。

04
AI编程 智能体 Apple

开源自训练引擎 Songe：利用 Mac 闲置算力在夜间让本地编程模型从报错中蒸馏进化

Sous Labs 在 GitHub 开源本地模型自训练引擎 Songe，支持通过 uv、pipx 或 macOS Homebrew 一键安装，并直接接入 LM Studio（支持 Apple Silicon MLX 量化模型）以及 opencode、pi 等 OpenAI 兼容编程助手。Songe 的核心设计基于“后见之明（Hindsight）”同策略蒸馏原则：白天开发者照常使用本地智能体写代码时，系统在后台静默记录每次工具调用后的真实后果，包括报错信息、命令返回值、重试动作与人工纠正；夜间当设备接通电源且处于空闲状态时，Songe 启动 Quick Dream 或 Deep Dream，让同一模型结合事后日志充当教师，针对自己曾踩坑的交互构建沙盒练习并微调轻量适配器。整个过程完全离线在本地执行，绝不重跑危险终端指令，且新生成的适配器必须在历史纠错测试集上明确胜出后才会被启用，支持随时一条命令回退版本。

Apple 独立开发 AI编程

老牌 Mac 开发者发布 Jetty Pro：用编程智能体打磨三个半月的 macOS Dock 替代器

知名 Mac 独立开发者 John Siracusa 正式推出桌面效率工具 Jetty Pro，并在次日火速发布 v1.0.1 修复更新。该工具允许用户在 Mac 屏幕任意边缘创建高度可定制的悬浮面板，自由收纳文件、目录、磁盘卷、应用、快捷指令、间隔条乃至废纸篓，既可作为原版程序坞的补充，也能彻底取而代之。他在随笔中坦承，原本只是想把六年前 SwitchGlass 的旧版 SwiftUI 代码喂给编程智能体，花一两天时间做出一个只放常用文件夹的小面板，结果在持续完善优化下投入了三个半月，并因为普通版受困于 Mac App Store 沙盒限制，索性放弃商店渠道转向官网直接分发。借助脱离沙盒与私有 API 调用，Jetty Pro 实现了官方 Dock 都未提供的细粒度控制，例如隐藏 macOS 27 中的“后台运行”图标列表、按面板屏蔽系统设置等应用的角标红点、打破图标圆角矩形限制以及按显示器独立配置显示策略，提供 14 天免费试用与每年 9.99 美元订阅方案。

AI编程 智能体

Hugging Face 论文精选 SWE-Gym-Verified：审计揭示 74% 智能体未解题源于测试标签错误

强化学习正在成为训练代码修复智能体的主流手段，但长期以来训练任务集的隐藏单元测试只验证了参考答案，很少有人核查测试反馈本身是否准确。Hugging Face 每日论文榜收录的研究《What Makes Good Data for Training Coding Agents? A Systematic Study on SWE-Gym》使用两组大模型对 SWE-Gym 进行了逐条执行复现审计，结果发现：在 9B 基座模型始终无法解出的题目中，高达 74% 存在测试集误判正确补丁的“假阴性”缺陷；而在全部通过测试的补丁中，也有约四分之一属于宽松测试放行的“假阳性”错误修复。研究团队随后修复并清理问题任务，在 GitHub 开源包含 1,087 条全执行证据验证任务的 SWE-Gym-Verified 数据集及审计管线（github.com/Arist12/SWE-Gym-Verified）。对比实验表明，在同等模型规模下使用清洗后的数据集训练策略，其在 SWE-bench Verified 与 SWE-bench Pro 上的得分分别提高 2.4 分与 2.7 分，印证了奖励信号可信度比单纯扩充样本量更为关键。
