jev-ultrafast：基于轻量决策流的极速低成本网页智能体

针对传统网页操作智能体调用完整多模态大模型延迟高与 Token 开销巨大的痛点，browser-use 团队推出了 jev-ultrafast 框架。该框架将 DOM 元素筛选与动作执行拆解为非自回归快速决策步进，仅在关键语义理解环节调用重型视觉模型。实测在网页表单填写、数据抽取与链路跳转等场景中，单次任务开销下降逾 80%，响应速度显著提升。

来源仓库：https://github.com/browser-use/jev-ultrafast

Ollaya：面向本地非自回归决策模型的即插即用管理工具

作为针对决策类模型（Decision Models）的本地化运行工具，Ollaya 借鉴了 Ollama 的极简交互体验，专注于一键拉取、管理与本地运行单步决策和评分模型。开发者通过标准 CLI 或本地 HTTP API 即可调用结构化判定能力，无需配置复杂的 PyTorch 环境或依赖云端鉴权，降低了智能体系统本地化部署的门槛。

官方主页：https://ollaya.dev/

Kev：基于开源底座的高性能本地决策模型训练框架

由 Jared Palmer 发起的开源项目 Kev 探索了在主流开源大模型之上构建结构化决策模型的方法。Kev 提供了从数据集构建、轻量化 LoRA 微调到非自回归头部分类训练的完整工作流，帮助开发者针对专属代码库或垂直业务场景训练出千参数量级、响应速度在 10 毫秒内的私有决策模型。

来源仓库：https://github.com/jaredpalmer/kev

Laya-MLX：专为 Apple Silicon 优化的毫秒级原生决策运行时

紧随非自回归决策模型架构演进，Laya-MLX 针对 macOS 与 Apple Silicon 统一内存架构进行了底层算子优化。借助 Apple MLX 框架的 Metal 加速，在 M 系列芯片上将单次选择、打分与布尔判断的端到端耗时压缩至 7 至 14 毫秒，且完全规避了常驻内存开销，为 macOS 原生软件集成端侧智能体决策提供了基础设施。

来源仓库：https://github.com/mizorewww/laya-mlx

git-bug：完全内嵌于 Git 对象的去中心化离线 Issue 追踪系统

在 Hacker News 获得广泛热议的 git-bug 实现了将 Bug 追踪与 Issue 讨论完全存储于 Git 仓库底层对象中。不同于依赖第三方托管平台的传统工单，git-bug 支持完全离线提交、随 Git 分支同步推送合并，并提供终端 TUI 与本地 Web 交互界面，为独立开发者与分布式开源协作提供了纯净、可控的项目管理方案。

来源仓库：https://github.com/git-bug/git-bug

Hugging Face 论文精选：面向通用任务与运动规划的代码智能体

最新入选 Hugging Face 每日论文的《Coding Agents for Generalized Task and Motion Planning Problems》探讨了如何将代码生成智能体与经典任务运动规划（TAMP）相结合。论文提出通过生成可执行的符号化规划代码与断言验证逻辑，智能体能够有效求解长程多物体操控与物理约束，表现优于传统黑盒策略。

论文地址：https://huggingface.co/papers/2609.30233
