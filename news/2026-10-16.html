Meta 正式开源 816B 多模态旗舰模型 Muse Spark Open：深度优化 Apple Silicon，两台 M5 Ultra 实现 1TB 统一内存桌面级智能体

大模型 智能体 Apple

Meta 官方正式发布并开源前沿多模态大模型 Muse Spark Open 权重。该模型采用混合专家（MoE）架构，总参数量达 8160 亿，每个 Token 仅激活 420 亿参数，配备 100 万 Token 上下文窗口。模型专为长程软件工程与复杂智能体任务打造，特别针对苹果统一内存架构进行了底层优化。借助最新版 MLX 框架，仅需两台配备 M5 Ultra 的 Mac Studio 即可通过每秒 1.2TB 的内存带宽组成 1TB 统一内存工作站，在本地桌面端完整运行万亿级参数模型。官方实测展示了该模型驱动的 Muse Code 在无需云端支持的情况下，自主为开源 Mastodon 客户端 Ice Cubes 编写 Bug 修复代码、通过编译并提交拉取请求，以及逐帧分析视频驱动 DaVinci Resolve 完成全自动竖屏裁切与剪辑。

信源：Meta AI Research / Hugging Face research.meta.ai/blog/muse-spark-open ↗

Goodfire 联合创始人 Nick Cammarata 长文颠覆可解释性共识：神经网络机制本就整洁，递归泛化推翻七年叠加性迷思

大模型

前 OpenAI 核心成员、Distill 经典论文 Zoom In 合著者 Nick Cammarata 发布长篇研究成果《Neural Networks Are Already Clean》，系统反思并推翻了长期主导机械可解释性领域的“叠加性（Superposition）”假设。过去学界普遍认为神经网络在神经元不足时会将互不相干的概念任意混叠折叠，从而必须训练外置的稀疏自编码器（SAE）进行解耦拆解。Cammarata 通过详尽的实验回溯证明，早期的多义性表象本质上是落后网络架构溢出、弱解释工具与特征可视化奖励作祟所致，神经元的真实运作机理是分形自相似的“递归泛化”。在对 Qwen3-32B 与万亿参数规模 Kimi K3 的实测审查中，约 90% 至 97% 的神经元极性均具备高度整洁、单一可读的功能意图，证实人类无需绕道外挂重构网络，即可直接对其物理机制开展常规白盒科学分析。

信源：Goodfire Research / Hacker News already-clean.goodfire.com ↗

Anthropic 在 Claude Code 推出 opusplan 模式：以高智力模型生成编排脚本，调度并发轻量智能体集群破解上下文膨胀

AI编程 智能体

针对大型工程代码库维护中自主智能体上下文迅速耗尽、单次重构成本过高的痛点，Anthropic 在最新 Claude Code 2.1.300 中正式引入 opusplan 配置模式。该模式倡导“高推理规划与低成本执行解耦”范式：在需求分析与架构设计阶段由旗舰模型 Opus 深度通读上下文，将复杂改造拆解为结构化的执行脚本与依赖任务图；随后将具体的文件检索、代码片段补丁与单元测试执行委托给并发运转的轻量级 Sonnet 或 Haiku 智能体集群。由于编排脚本承担了全局状态跟踪职责，Opus 无需在整个多轮工具调用流中持续驻留庞大上下文，在大幅提升百万行代码库跨文件重构吞吐量的同时，将长程工程任务的 Token 开销缩减数倍。

信源：Anthropic Claude Code Docs / X 热议 code.claude.com/docs/en/model-config ↗

阶跃星辰开源 600B 混合专家模型 Step 5 Preview：激活 27B 与百万上下文，主攻长程代码智能体与低推理开销

大模型 智能体

阶跃星辰正式开放 Step 5 Preview 混合专家大模型权重，同步在 Hugging Face 与 ModelScope 释出 BF16 及 FP8 两种精度版本与配套推理工具链。该模型采用稀疏 MoE 架构，总参数量达 6000 亿，每个 Token 仅激活 270 亿参数，原生支持文本与视觉多模态输入，最大上下文窗口达到 100 万 Token。模型针对软件工程代码改写、复杂知识工作流与金融分析等长程智能体场景进行了深度专项训练。官方性能评测显示，Step 5 Preview 在综合智能指数中位列前茅，单任务推理运行成本仅约为同级别商业闭源模型的八分之一，并提供面向 vLLM 与 SGLang 的原生服务端部署支持。

信源：Hugging Face / 少数派 huggingface.co/stepfun-ai/Step-5-Preview ↗

独立设计师 Robbie Tilton 开源 macOS 原生图片编辑器 Compositor：基于 Swift 与 Metal 构建仅 12MB，终结订阅制软件垄断

Apple 独立开发

针对商业图像软件日益臃肿、持续推行昂贵订阅制以及开源跨平台软件交互生硬的长期痛点，独立设计师 Robbie Tilton 在 GitHub 开源了专为 Mac 打造的轻量级原生图像合成与编辑工具 Compositor。软件采用纯 Swift 配合苹果底层 Metal 图形管线加速开发，安装包体积仅约 12MB（远低于主流商业软件超过 6GB 的磁盘占用），启动近乎瞬时。Compositor 遵循 macOS 原生人机交互规范，完整支持图层分组、混合模式、非破坏性蒙版与曲线色阶调节，并原生集成 PSD 格式解析能力。所有图像运算完全依托本地硬件完成，没有任何账号登录、数据回传或云端服务捆绑，发布后迅速斩获极客社区 6600 余颗 Stars。

信源：GitHub / GitDiscover github.com/robbietilton/Compositor ↗

Apple 智能国行测试版将于本月下旬开启推送：工信部完成模型备案换证，照片消除与写作工具首发亮相

Apple 大模型

在 10 月 15 日的在华线下媒体交流活动中，苹果首席执行官 Tim Cook 正式确认，Apple 智能国行 Beta 版本将于本月晚些时候随系统开发者测试版正式上线。首批落地功能包括系统级实时翻译、照片应用中的智能消除工具以及邮件备忘录中的写作辅助工具，深度整合的多模态 Siri 则仍在适配开发中。此前工信部电信设备进网许可信息显示，苹果旗下多款国行 iPhone 已完成进网许可换证，正式获得 Apple 智能、通义万相和通义千问三款大模型的官方备案编号，标志着苹果端侧模型与国内合规云端大模型服务商的深度协同架构正式进入实质性公测阶段。
