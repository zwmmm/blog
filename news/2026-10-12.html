Maurice Heumann 详述 5000 亿 Token 实战复盘：多智能体协作如何精准反编译大型 3D 商业游戏

智能体 AI编程

安全研究员 Maurice Heumann 发表长文，完整复盘团队耗时三个月、消耗超 5000 亿 Token 并调度 16 个自主智能体逆向反编译经典大型商业游戏的工程实践。团队在复盘中指出，初期依赖 Reviewer 审查智能体容易被工作智能体的虚构理由所误导产生无意识提示注入，且指令随上下文压缩迅速衰减；后期团队转向通过同款编译器生成的 OBJ 与游戏原版 EXE 进行字节级重定位匹配，构建出机器可验证的强客观验收标准。该机制使 83% 的游戏函数达到逐字节绝对一致，并证明在严密测试校验网格下，廉价轻量模型完全可以胜过缺乏约束的高推理模型。

patwalls 开源 Headroom：基于本地钩子的原生 macOS 菜单栏 Claude Code 用量监控轻量小工具

Apple AI编程 独立开发

独立开发者 Pat Walls 开源了专为重度终端 AI 编程者设计的 macOS 菜单栏小工具 Headroom。应用使用原生 Swift 与 AppKit 编写，体积仅约 267KB，代码量不足 800 行且完全无外部依赖。Headroom 通过接入 Claude Code 本地状态行钩子自动记录配额数据，无需配置 API 密钥或读取系统钥匙串，全程零网络请求。菜单栏可常驻显示 5 小时会话窗口与 7 天滚动上限进度百分比、上下文窗口填充度、实时会话美元消耗及限额倒计时，有效防止任务中途意外触顶中断。

信源：GitHub / walls.sh github.com/patwalls/headroom ↗

Niko1221 开源 Strata：在消费级 PC 本地流畅运行 125B 细粒度专家大模型的高性能推理引擎

大模型 AI编程 智能体

开源项目 Strata 突破了消费级电脑运行超大参数模型的硬件瓶颈，使仅配备 12GB 显存的普通显卡能够离线运行 1250 亿参数的 Qwen3.8-Flash-Next 细粒度混合专家模型。Strata 创新性地采用显存、内存与高速固态硬盘三级协同分层机制，将最频繁调用的数千个专家驻留于显卡，其余专家分布在内存与 SSD 动态检索，并配合轻量投机解码实现输出加速。本地服务对外直接提供标准的 OpenAI 与 Anthropic 兼容端点，为 Claude Code、Cursor 和 Codex 终端智能体提供了零数据泄露风险且完全免费的本地高智力后盾。

信源：GitHub Trending / 开源生态 github.com/Niko1221/Strata ↗

Andrej Karpathy 发文引发热议：公众认知与前沿智能体实战体验之间的能力鸿沟正在加剧

大模型 中推 智能体

著名人工智能研究员 Andrej Karpathy 近日针对大模型发展现状发表观点，指出社会大众与前沿从业者对 AI 能力的认知分歧正达到前所未有的程度。普通消费者在日常网页对话中接触受限版本与通用闲聊，频频遭遇幻觉与逻辑短板，容易将其归为华而不实的文本补全；而深入使用 Claude Code 与 Codex 等多文件编程智能体的研发者，则依托可验证奖励强化学习（RLVR）与复杂工具链，亲身感受到了具备工程重构能力的生产力跃迁。这种分化表明当前 AI 正在向专业化深度验证方向快速收敛。

陶哲轩发表 Math 2.0 主题演讲：形式化证明 Lean 与前沿 AI 协同重塑数学研究工程化范式

大模型 智能体

菲尔兹奖得主陶哲轩（Terence Tao）在加州理工学院发表题为《Math 2.0》的前沿学术讲座，深入探讨现代数学研究范式向计算机化与模块化转型的未来图景。陶哲轩指出，交互式定理证明语言 Lean、自动化求解器与大语言模型代码智能体的结合，正在使数学证明从传统的孤立纸笔推演转变为类似开源软件的模块化协作工程。大语言模型擅长在顶层提供证明策略与直觉草图，而形式化内核则负责机器级严密纠错与全链路类型检查，为人类与智能体共同探索前沿复杂猜想开辟了全新路径。
